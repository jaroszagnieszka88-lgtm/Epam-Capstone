# Capstone

## Prerequisites

Before running this project, make sure you have the following installed:

* **Node.js** (25.5.0 or newer)
* **npm** (11.8.0 or newer)

---

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

---

## Development

To start the development environment (TS + SCSS) run:

```bash
npm run dev
```

This will:

* Compile **TypeScript (`.ts`) files** into JavaScript
* Compile **SASS (`.scss`) files** into CSS inside the `dist/` folder
* Launch a local dev server (at http://localhost:3000)
